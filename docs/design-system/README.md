# NetScript design system

The written half of the Fresh UI design system (epic #2412). Figma file `pGRLnkPPRZJZy74evNcQBr`
owns the values; these files own the rules and the names.

| Start here              | What it is                                                                                     |
| ----------------------- | ---------------------------------------------------------------------------------------------- |
| `GUIDELINES.md`         | NetScript Custom Design Guidelines: the token contract, the quality method, how to add a theme |
| `themes/<id>/DESIGN.md` | One theme's specification (Google Labs DESIGN.md format, alpha), with resolved values          |
| `themes/<id>/SKILL.md`  | The working procedure an agent follows to build in that theme                                  |
| `themes/_template/`     | Start points for a new theme                                                                   |
| `docs-site.md`          | Handoff for the docs-site revamp in Utility, the NetScript default                             |
| `reference/docs-site/`  | Figma exports of the docs designs and the Utility specimen                                     |

Themes: `studio` (seven flavors; Utility is the NetScript default), `tonal`, `bloom`, `cupertino`,
`liquid`, `fluent`, `brutal`, `filigrane`, `terminal`, `tactile`, `pixel`.
