# NetScript design system

Specifications for the Fresh UI design system (epic #2412). The NetScript Figma library owns the
values; these files own the rules and the names.

| Start here              | What it is                                                                                     |
| ----------------------- | ---------------------------------------------------------------------------------------------- |
| `GUIDELINES.md`         | NetScript Custom Design Guidelines: the token contract, the quality method, how to add a theme |
| `themes/<id>/DESIGN.md` | One theme's specification (Google Labs DESIGN.md format, alpha), with resolved values          |
| `themes/<id>/SKILL.md`  | The procedure an agent follows to build in that theme                                          |
| `themes/_template/`     | Templates for a new theme                                                                      |

Themes: `studio` (seven flavors; Utility is the NetScript default), `tonal`, `bloom`, `cupertino`,
`liquid`, `fluent`, `brutal`, `filigrane`, `terminal`, `tactile`, `pixel`.
