# macOS 27 token preset

Read DESIGN.md beside this file first. Select `theme-macos-27` from the Fresh UI
registry or set the token builder preset to `macos-27`. Use the installed preset and
font metadata to set `data-theme="macos-27"`, `data-scheme="light|dark"` and
`data-density="comfortable"`.

Keep the theme's own font, geometry, chart and surface roles. Resolve aliases
through Theme set mode B, then Theme B mode macOS 27; do not substitute the
inspired language packs or other Studio flavors. Figma owns values. Add semantic
name aliases through the token source layer instead of hand-editing generated CSS.

Check text and code syntax at 4.5:1 and chart series at 3:1 on the intended paint
stack. An exact exclusion is reported source debt; do not claim the contrast
burn-down is complete. Read the compiler's sourceStyle metadata for mixed emphasis
style names. Leave application-owned copied files available for the app to extend.
