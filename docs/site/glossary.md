# Glossary

This page defines the terms the NetScript docs use, maps each one to the file or API it lives in,
and links to the page that teaches it. Use it as a lookup: when a page uses a word such as
**contribution**, **single-active-backend**, or **durability tier**, find its precise meaning here,
then follow the link back.

{{ comp callout { type: "note", title: "How to read an entry" } }}
The middle column names the <strong>API or file</strong> a term maps to: the thing you type or open.
Each description links to the page that teaches the term. Terms are alphabetical within each table.
{{ /comp }}

These are the terms you meet first, in the [Quickstart](/quickstart/), the
[tutorials](/tutorials/), and the [architecture overview](/explanation/architecture/).

## Less common terms

These terms appear once you go past the happy path: the toolchain, the data layer, the auth seams,
and the moving parts under a running plugin.
