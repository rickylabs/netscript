# Docs kit

Use these galleries to inspect documentation primitives in light and dark schemes.

- [Callout gallery](/design-system/docs-kit/callouts/): semantic notices, tones and links.
- [Code gallery](/design-system/docs-kit/code/): syntax colours, filenames, tabs and Copy.

## API kind tags

Kind tags share the syntax palette. Names stay at full text contrast; labels and square dots identify each kind without relying on colour.

| Symbol | Kind | Description |
| --- | --- | --- |
| `Service` | class | A class uses the type role. |
| `ServiceContract` | interface | An interface uses the keyword role. |
| `ServiceOptions` | type alias | A type alias uses the keyword role. |
| `createService` | function | A function uses the function role. |
| `start` | method | A method uses the function role. |
| `activeService` | variable | A variable uses the number role. |
| `DEFAULT_LIMIT` | constant | A constant uses the number role. |
| `ServiceState` | enum | An enum uses the number role. |
| `serviceModule` | module | A module uses the foreground role. |
| `Services` | namespace | A namespace uses the foreground role. |
| `ServiceCard` | component | A component uses the function role. |
