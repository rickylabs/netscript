# Tokens v2 source-stage lesson — 2026-10-28

The S1 source stage reached two independent FAIL_FIX verdicts and stopped under
the dispatcher's leaf retry limit. The PR is a draft; S1 is not complete.

Alias-only validation and graph coverage do not establish an appropriate
typography map. NS One's new line-height aliases must be checked against the
corresponding text sizes; one shared dimension is insufficient. Preserve every
existing declaration and verify the new roles separately.

Official DTCG schema bundles embed overlapping IDs, so compile the format and
resolver bundles with separate Ajv registries. A color fallback has six hex
digits; alpha is a separate field. Transition shorthands need a transition
composite, including their timing curve, rather than a duration alone.

When stopping before the output adapter is implemented, stage new sources
separately so the existing frozen pipeline continues to work. Keep failed
verdicts and the precise remaining scope in the run record.
