## Output slice lessons

- Color.js 0.5.2 can return boxed numeric coordinates as well as boxed alpha. Normalize with Number before a finite test; treating a boxed coordinate as invalid silently erases the primitive color. Preserve alpha through native mix computation; quantizing to hex before constructing the DTCG result loses the intended .12 alpha.
- CSS semantic var references and SD-resolved JSON/Figma values must share override edges. Re-link context dependencies to semantic roles before applying the final override; preserve each role's own primitive edge to avoid self cycles. Shadow composite derivations need the same treatment as mixes.
- Adding registry themes also changes the app-owned design-gallery catalog. Generate that snapshot through gen:assets-barrel and keep its drift test. Updating only the embedded fresh-ui registry leaves the gallery gate red.
- Public type aliases derived from exported tuples also need those tuples exported for deno doc --lint. New token API doc lint is clean; the full export audit still exposes the pre-existing interactive findings instead of treating the new entrypoint as the whole package.
- Figma FLOAT dimensions are pixels. Convert legacy rem inputs with the same 16px root contract used by the legacy resolver; exporting only the numeric field loses the unit. Durations are exported as milliseconds. Check every computed dimension, including legacy aliases carried by non-default presets.
- Figma name migrations must apply at the round-trip output boundary as well as at source import. Otherwise a width variable can still carry WEB syntax that names a color. Keep the raw approved snapshot intact and validate every exported syntax binding against the generated token's type.
- Hex custom-property declarations followed by oklch do not provide feature detection. The browser accepts arbitrary custom-property text. Emit base fallbacks and gate modern color functions with @supports.
