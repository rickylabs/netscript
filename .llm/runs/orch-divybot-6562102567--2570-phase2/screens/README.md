# Seeded live acceptance captures

Generated with the current local CLI, SQLite service (40 canonical seeded records), workers and streams installed and linked. A real app-owned fixture job fetches four live health endpoints and reports each completed probe; its persisted executions and emitted events populate the Overview. No job numbers or events are inserted into shipped templates. The auth provider is absent, so sign-in truthfully shows connection/setup state. Background health discovery is not linked to the web app and is distinguished from actual worker readiness and execution state.

All eight routes plus the command palette passed at 1440px and 390px in both themes, with no page errors or horizontal page overflow. Browser interactions include lowercase reference search/URL persistence, selection/CSV, numeric refund export, empty/out-of-range pages, Settings save and real palette results/Escape. JSON browser evidence is in browser-matrix.json. Viewport companions retain readable text on long pages.
