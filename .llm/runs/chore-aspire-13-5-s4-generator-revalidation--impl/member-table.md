# Aspire 13.5 TypeScript member and deploy-command re-validation

## Source contract

The API rows use the official Aspire TypeScript reference pages (version `13.5.1`, except the
Browsers preview page) linked below. The reference renderer flattens some generated TypeScript
option objects into positional parameter lists. Where that presentation conflicts with emitted code,
the restored SDK projection is authoritative: S2 receipt `01-restored-module-grep.raw.txt` records
`withHttpHealthCheck(options?: WithHttpHealthCheckOptions)` in the 13.5.3-restored module and the
generated options-object call sites. Verdicts compare the member surface with the pre-13.5 generator
contract: `unchanged`, `changed`, or `removed`.
