# Browser scaffold memory

The actual scaffold design routes are under `packages/cli/src/kernel/assets/app/routes/(design)/design/`. They are intentionally ignored outside development mode in the generated Vite configuration. Use the scaffold dashboard dev task for the browser harness. ThemeToggle uses localStorage key `ns-theme` and a `data-theme` attribute on the document element; its accessible name is “Switch to dark mode” / “Switch to light mode”. `netscript-dev init` supports `--db none --no-aspire --no-git --editor none --ci --yes` without a service. Use the live help to confirm flags.
