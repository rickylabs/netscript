A freshness gate must compare before it repairs. The old token task regenerated output before diffing, so a hand edit could disappear silently. Keep check mode read-only and prove that an edited artifact remains edited when the check fails.

Reproduce against current main. The dispatcher’s older shallow checkout had a different private dependency graph; only the actual main baseline reproduced the LRUCache failure. Resolve the exact upgraded package through Deno, then keep the reviewed lock graph repair narrowly scoped.

An existing UI needs evidence before redesign. Preserve complete axe scans and screenshots of today’s gallery. Exact node/count baselines can gate new regressions without hiding whole rules, but they must also reject stale allowances and record the existing debt. A new-rule-only negative control is insufficient: test new targets under known rules, duplicated nodes and resolved/stale allowances too.

Browser tooling peers need a shared exact core version. A broad axe adapter peer otherwise selected a second Playwright core, producing incompatible Page types. A direct exact core dependency and frozen npm install make the matrix reproducible.

Command success and scope sufficiency are different. Durable receipts prove the named token/browser commands. Missing Docker/Aspire prerequisites leave full scaffold runtime unproven; do not convert that limitation into a success claim or weaken the existing gate.
