## Lessons for Promotion

| Lesson                                                                   | Pattern                                                                                                                                                                                                                                                                                                                                                                      | Applies to                                                                       | Confidence |
| ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ---------- |
| Derive expected keys from the runtime schema value, never a literal list | When a compiler/emitter must track a schema-owned contract, assert `Object.keys(Schema.shape) ⊆ emittedKeys` behind an `instanceof z.ZodObject` guard. One-way subset tolerates legitimate emitter-only keys (`executionType`) while making a dropped contract key a loud failure — and adds **zero** duplicated constraints, so the schema stays the single source of truth | Archetype 5 (plugin connectors) and any code generator over a Zod-owned contract | high       |
| A byte-golden snapshot cannot detect a schema-only change                | The generated bytes do not move when a schema gains a key, so the snapshot stays green and the omission is invisible. Pair every generated-output snapshot with a semantic key-parity assertion — this is also the AP-18 remedy                                                                                                                                              | any generator with a golden test                                                 | high       |
| Verify the _generated_ artifact type-checks, not just the generator      | A plugin's `check` task type-checks the emitter's string literals, never the module they produce. Regenerate from baseline and candidate, rewrite bare specifiers to absolute file URLs, and diff the `deno check` error sets — this isolates new type errors without a runtime/E2E gate                                                                                     | any code generator evaluated under a runtime-gate prohibition                    | medium     |
| Prove a new test can fail before trusting it                             | An assertion whose extraction step can silently match nothing is worse than no assertion.
