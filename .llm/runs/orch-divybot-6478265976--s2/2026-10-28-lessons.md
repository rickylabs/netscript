# 2026-10-28 lessons

- A TypeScript manifest may derive theme metadata, preview paths and release versions. Before moving its authoring into JSON, preserve or gate each derivation explicitly.
- A preview parity test must preserve the existing `static/` destination; alias syntax is not interchangeable in compatibility fixtures.
- Ajv bundles the HTTP draft-07 metaschema URI; normalize the schema adapter's in-memory dialect URI while retaining the unmodified upstream snapshots and hashes.
- Structured test wrappers can report zero failed tests with a nonzero process exit after a top-level module error. Require exit 0 and inspect processFailure. Doc-lint per-entrypoint exit codes also matter when a combined summary looks clean.
- No independent passing verdict means no signed-off slice and no READY claim, even after local fixes make gates green.
