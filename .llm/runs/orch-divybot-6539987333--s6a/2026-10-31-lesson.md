# 2026-10-31 — Utility delivery lessons

A single legacy preset is insufficient for isolation checks. NS One aliases primary-border and primary-stroke, so it hid an accidental base-rule substitution. Tonal and macOS27 exposed it; select each preset with its actual data-theme and data-scheme attributes.

A passing browser assertion set still needs image inspection. The complete pass exposed missing overlay focus rings, and inspection caught a Card/DataTable import-order dependency. Keep assertions tied to owned component parts, and explicitly distinguish unstyled headless primitives from the shipped registry inventory.

Preserve historical migration fixtures. Declare a reviewed additive dependency in the expectation instead of rewriting the historical baseline; inspect rendered parts rather than fixed VNode child indexes.

Prove copied components in a generated application route. A build can tree-shake an unused component; the temporary CodeBlock route proved its inline npm import, server bundle, syntax colors and original clipboard source through Fresh Vite.

Freeze source and evidence before independent evaluation. When upstream changes approved token values, merge those values and refresh affected evidence. Identical carrier regeneration may update mtimes without changing hashes. Keep runtime failures and dependency advisories explicit; local static/build proofs do not replace the runtime gate.
