# Local browser proof

Install the checked-in `tools/fresh-ui-browser` npm lock with `npm ci --ignore-scripts`.
The browser binary cache may exist while OS shared libraries are absent. Without root,
download Debian library packages into the private project run and extract with dpkg-deb;
set LD_LIBRARY_PATH for that browser process only. Do not rely on a prior worktree's
node_modules: it can disappear during another run's cleanup.

Real API-created references are longer than seed references. Verify compact desktop table
cells as well as whole-page overflow; a string can overlap the owner without widening the page.
