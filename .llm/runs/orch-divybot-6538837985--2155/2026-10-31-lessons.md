- Trace behavior from shipped source even when the MCP documentation corpus disagrees. MCP still had the unsupported-defer claim; the runtime scheduler and existing tests prove defer is live.
- `TriggerDefinition.retry` exists, but builder specs omit it. A documented workaround must export only the final definition, provide a full replacement policy, and distinguish runtime registration from static contribution counts.
- Use `defineJobHandler(payloadSchema, handler)` for current public worker examples; old one-argument prose is not evidence of the current signature. Compile actual fences beyond the standard snippet gate's Tier-1 floor.
- API + combined is the workers default. Packaged plugin entrypoints and generated `workers/runtime.ts` wrappers describe different deployment surfaces. Keep exactly one scheduler owner for a job set.
- An applied-key guard does not make external effects at-most-once. A write receipt's acceptance does not prove acknowledged delivery. Await outcomes and keep business keys stable across job retries.
- A docs-only assignment that forbids packages can still invalidate `packages/cli/src/kernel/assets/agent-docs-prose.generated.ts`. Measure site-to-carrier freshness and report the boundary to the coordinator. `check:publish-assets` can pass against the old corpus while the rendered docs are newer. - Use the final exact-head PR evaluator comment as the immutable handoff; committing that final verdict into the evaluated branch would change the head it certifies.

- Restoring a redirect stub as real content can add a new Aspire scan path even though the filename already existed. Regenerate the maintained manifest and confirm only the intended public-page row changed; parity must stay strict.
