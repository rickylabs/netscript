Expose a separate CommandOutboxRetentionStore.pruneSettled({now,completedRetentionDays?,limit},signal?) from the PostgreSQL relay factory without breaking existing relay-only implementations. Validate finite positive days (default seven), finite date, integer limit 1..100; retain every leased row (even expired leases) and pending work. Select at most limit IDs, delete only those IDs with all eligibility predicates repeated at deletion.

Expose createPrismaSagaCommandRetention(root,{transactionTimeoutMs,completedRetentionDays?}) with prune({now,limit},signal?), composed with the relay retention method. Numeric completedRetentionDays follows group retention.completedDays (default 7); callers create one configured sweep per database/policy, optional sagaId filter for multiple configured groups. Each call performs a fixed number of statements and selects/deletes at most limit rows per family (2*limit total). Delete only selected marker identities, repeat terminal/time/version predicates; locks prevent concurrent state revival during delete. Never age from key creation. Missing/invalid terminal evidence preserves markers.
