## Locked design

1. Install the exact NetScriptCommandOutbox model through existing sagas.prisma schema contribution. Preserve fixture column types/defaults/index. Ship database/command-outbox.migration.sql with three reviewed CHECK constraints through the manifest migration axis. Extend existing plugin schema-copy/integrity paths to install *.migration.sql sidecars along with Prisma fragments. Database migration tooling discovers those sidecars beneath the schema tree, generates with --create-only, appends pending immutable SQL contributions to the newly generated migration BEFORE migrate deploy, and verifies status. Never runtime DDL. Track contribution identity/hash in migration comments; unchanged contributions are skipped and changing an applied contribution fails with guidance to use a new name. If no Prisma model diff exists, pending SQL gets its own migration artifact. Existing projects lacking contributions follow the current flow.

2. Bound the QUERY work with primary-key keyset pages, not an eligibility-filtered full scan. Outbox pruneSettled({now,completedRetentionDays?,limit,afterId?},signal?) selects at most limit rows by id and deletes only selected IDs with settled age and both lease-null predicates at deletion. Return scanned/deleted counts plus nextAfterId; end-of-page wraps on the host's next scheduled cycle. Separate retention port keeps existing relay fakes compatible. Defaults seven days, limit required integer 1..100; validate before IO. No secondary index required.

3. createPrismaSagaCommandRetention(root,{transactionTimeoutMs,completedRetentionDays?,completedRetentionDaysBySaga?,outboxRetentionDays?}) exposes prune({now,limit,cursor?},signal?). Applied-key scan uses composite PRIMARY KEY (instance_id,key_hash) and LIMIT, joins at most that page to indexed canonical parent state. Parse metadata in TypeScript with validation; malformed/missing state or timestamps survive without aborting other records. Terminal statuses completed/failed/cancelled/compensated; timestamp completedAt or terminal updatedAt, never marker created_at. Group override map resolved per selected saga id; default seven days. Shared outbox window defaults to maximum of default and all overrides, or explicit outboxRetentionDays. Prune outbox once per call.

4. Selected expired applied markers are candidates only. In a bounded callback transaction lock selected parent states, ordered by instance_id, FOR UPDATE SKIP LOCKED. Re-read/validate fresh status, terminal time, policy and version against candidate; only then delete selected composite marker keys, with parent version and envelope equality in the DELETE. Parent lock fences concurrent state revival. No parent means preserve; canonical cleanup must follow the replay sweep. Every call reads/deletes <=limit markers and <=limit outbox records, with <=limit parent locks, bounded request sizes and finite transaction timeout. Return per-family scanned/deleted counts and resumable keyset cursors.

5. Deterministic tests use a non-exported transaction-client wrapper, intercepting the candidate query after it returns and changing real PostgreSQL rows from a second connection before the lock/delete. No production test hook. Negative controls map to pending/settled age, lease, terminal status, completion age, fresh status/deadline/version/envelope recheck and LIMIT guards. Test malformed timestamps, multiple group policies, concurrent state lock, repeated keyset progress and per-call caps.

6. Consumers with a byte-equivalent copied model use existing schema deduplication; document adopting schema ownership without dropping the table, baselining prior migrations and validating constraints. Conflicting variants require explicit application migration alignment; installer must retain existing collision errors. Prove equivalent copied-model installation.
