## 1. Scope in one screen

Add GitHub Copilot Pro+ to the agentic runtime as (a) a typed `github_copilot` transport served by
OpenCode's native GitHub Copilot provider, placed by owner ruling behind native Claude/Codex/`agy`
and ahead of OpenCode Go/Ollama/OpenRouter, with launch-time catalog attestation; (b) a Copilot Pro+
AI-credit expense guard that fails closed; (c) a typed Agent Tasks REST dispatcher/status/watcher
that defaults to no-live-dispatch. OpenHands stays. No CI-approval policy change. No skill-tree
duplication. No billable task before an explicitly authorized canary.
