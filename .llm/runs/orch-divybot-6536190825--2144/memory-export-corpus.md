# MCP export-corpus freshness

After changing public package/plugin exports, run `deno task gen:mcp-export-corpus` from a clean committed package/plugin read set, then commit the generated artifact. `deno task check:mcp-export-corpus` checks working-tree freshness, but the generator regression tests clone committed HEAD. Running those tests before committing the refreshed artifact reproduces the old stale-corpus failures even if the working artifact is correct. A stale artifact can also make the byte-comparison assertion exhaust diff-buffer allocation; fix generation rather than weakening the test. The decisive structured test invocation is `deno run --allow-read --allow-write --allow-run .llm/tools/run-deno-test.ts -- --allow-all --unstable-kv --no-lock .llm/tools/docs/generate-export-surface-corpus_test.ts` after the artifact commit.
