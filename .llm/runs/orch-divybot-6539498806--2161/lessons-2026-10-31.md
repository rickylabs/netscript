# Lessons — 2026-10-31

- Static registry selection has more than one writer: check both generate-plugins entrypoints and plugin authoring commands before adding a source policy.
- A first-line marker can be read in the existing read-only inspection sandbox. Share one selector and report excluded candidates, preserving strict unmarked-module failures.
- Protocol additions should be optional and validated for paths, overlap, file existence and capacity; old producer payloads must keep working.
- Test fixtures must satisfy existing suffix rules. Saga fixtures use -saga.ts; a differently named helper was never a registrable candidate.
- Processor readiness can be checked in an installed project with isolated dependencies, but that remains separate from the coordinator-owned full runtime CI verdict.
- CLI lint/format require a style-only config with no inherited exclusion patterns; count processed files before claiming a pass.
- New public exports require regenerating the MCP export corpus; let the repository generator own its compressed carrier.
