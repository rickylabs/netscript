# 2026-10-31 — notification boundaries are observable state boundaries

A synchronous mutation loop prevents transaction interleaving, but callbacks
inside that loop can still read incomplete storage. Treat notification dispatch
as a separate phase after all mutations. Capture each event while mutating to
preserve payload history without dispatching early.

An async watch-consumer test alone cannot establish synchronous ordering: its
continuation already runs after the loop. Pair public watch delivery with reads
captured at the registered handler boundary, assert outside swallowed callbacks,
and require an original-production-file negative control for each new test.

The regression suite spans both key and prefix subscriptions, every mutation
kind, repeated keys, TTL sweep and standalone notification semantics. See
regression-evidence.json and memory-validation.md for results and commands.
