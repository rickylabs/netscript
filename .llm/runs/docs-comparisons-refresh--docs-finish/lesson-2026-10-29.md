# Lesson: source-checked comparisons need more than snippet extraction

Scenario code stored in component data is invisible to Markdown fence-only scans. Keep the exact snippet in source modules, render those bytes, and check the same files as consumers against current local export maps. Preserve inference: package isolated-declaration requirements are not application API type checks.

Use real browser checks for progressive enhancement. A native select with hidden panels can look correct while links to nested headings leave content hidden. Cover both panel and descendant fragments, no-JS HTML, Markdown twins, keyboard focus and each configured viewport/theme. Inspect a screenshot for spacing that structural checks miss.
