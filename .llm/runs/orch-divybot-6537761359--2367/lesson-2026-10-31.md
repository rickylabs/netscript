# Lesson — 2026-10-31

Reject ambiguous options at the canonical-key boundary, before translating a second value. A raw
key check misses aliases; comparing values still permits silent duplicate input. Canonical lookup
plus Map.has preserves the established tokenizer and needs no replacement parser.

Consumer copies matter: NetScript embeds the pure Postgres normalizer into both generated engine
modules and Prisma configs. Regenerate with gen:assets-barrel, exercise actual config loading, and
include those consumers in the revert negative control. Public error-reason lists and Unreleased
notes must follow new refusal reasons.

Use the structured test wrapper's grouped failure names to prove every regression goes red under
reversion; aggregate failure alone can hide tests that never exercised the bug. Keep private raw
receipts out of public artifacts while retaining their safe result summaries and report hashes.

CLI lint/fmt inherit root exclusions even through the CLI member config. An explicit temporary
standalone config with the same style values lets scoped wrappers process selected CLI files without
changing repository policy. Treat coverage refusals as failures until every selected file is verified.
