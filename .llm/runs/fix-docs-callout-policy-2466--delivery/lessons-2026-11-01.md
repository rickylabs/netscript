# Lessons — 2026-11-01

- Callout output has two paths: component contract and authored data-alert metadata. Canonicalizing
  only CALLOUT_TYPES leaves authored aliases unsupported. Test both through the real renderer.
- A caller supplying one trusted token exception does not close an analyzer's accepted map keys.
  Restrict the type and runtime lookup; prove forged extra keys cannot suppress direct/alias uses.
- `analyzeStylePolicy` is serialized into Chromium. Keep its runtime constants inside the function.
- Root lint excludes docs tooling; a fail-closed all-excluded result needs an explicit docs config,
  not a green claim. Native structured wrappers give coverage counts and refusal evidence.
- Playwright grep matches the full project/file/test title: an anchored test-name expression can
  select no tests. Verify the actual policy artifact and expected finding for negative controls.
