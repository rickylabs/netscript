# Lesson — authenticated availability stays inside the existing auth pipeline

Model a missing/retired procedure as a denied authorization decision with a typed machine code,
then let the existing authenticated HTTP stage choose 404/410. Do not let retirement route around
authentication or shadow live contract/raw/internal policies. Compile exact paths once and resolve
from the same raw pathname as the served projection.

A negative control must retain the new types/tests and revert the runtime branches: otherwise a
compile failure does not prove the regression. Here the two tests failed precisely on the original
403 versus required 404/410, and the restored full service suite passed 642 results.

The plan gate earned its cost by identifying executable documentation tests and a public resolver
marker omitted from the initial surface inventory. Explicit gates make the docs acceptance auditable.
