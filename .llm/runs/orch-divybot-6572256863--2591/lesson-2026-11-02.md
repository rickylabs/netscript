# Documented scaffold acceptance

Runtime fixtures that repair links or restart children can mask failures in the documented order.
Test the documented sequence in an independent pristine workspace before fixture-only interventions.
Use real post-seed execution with its correlation identity, and assert the actual stream-backed
Activity projection after a committed mutation. A generic healthy resource or a manually triggered
sample cannot prove either wiring contract. Keep both deliberate fault controls alongside the gate.

Public execution DTOs may deliberately omit correlation keys. Bind provenance through the public
filtered route and parse regression fixtures through the real response schema. Preserve nested
errors from live controls so a gate failure identifies the application boundary. Canonical exact
AppHost cleanup is stronger than hoping a detached host appears in an enumerated process list.
Distinguish source review PASS from actual final-head runtime acceptance.
