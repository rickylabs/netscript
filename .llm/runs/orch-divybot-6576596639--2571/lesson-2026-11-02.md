# 2026-11-02 — Prove the generated consumer, including empty states

The documented `showcase:setup` recipe must be the acceptance path. A separate
wiring fixture can hide a broken install, registry identity or Aspire resource
name. The real `scaffold.showcase` gate caught missing shipping persistence;
restoring it proved the same saved order, completed job, three saga timestamps
and an activity item linking that order.

An empty durable conversation needs a finite authenticated catch-up before its
composer can enable. A live subscription alone waits forever on an unused
thread. The mounted browser test now proves first send, reopening another unused
thread, exact-offset tailing and native message/tool replay after reload.

A caller-owned service entrypoint does not change its installed plugin source.
Use `InstalledFrom` for registry discovery, inspect directory manifests before
legacy entrypoint fallback, and test workspace/local/file URL variants.

Keep heavy adapter imports behind the opt-in path. An eager Vite route-manifest
import changed ordinary CLI permissions; existing FFI-restricted CLI consumers
caught it. The corrected default output, including agent files, matches all 220
files at one identical destination against current main.

Deno pack emits npm metadata. A production consumer proof must preserve actual
name/version/compiled exports, close every first-party alias and run the app's
client/server build with source vendors removed. A passing local-source build
alone does not prove that boundary.

Save reviewer verdict text separately from launcher output. Private execution
logs contain routing metadata; public run files need only the review evidence,
repository-relative paths and exact candidate/tree hashes.

Architecture command success does not waive F-16 warnings. Compare immediate
children against main, counting subdirectories too. The final independent review
required explicit bounded debt and matching README deviations for the showcase
parents; no functional defect or new framework API was involved.
