### Findings

1. **major — `packages/cli/e2e/src/domain/http-contract.ts:73` — Served 502/503/504 responses are incorrectly retryable.** The leaf brief explicitly reserves retries for connection failures; acceptance box 3 requires a wrong-but-served status to fail immediately. This exception applies to every route, including authorization probes. An independent control expecting 401 received 503 followed by 401: the probe made two requests and passed. The new tests encode this weakened requirement. **Fix:** classify every unexpected served status as `mismatch`. Keep readiness waiting separate from exact-exchange assertions, and add negative controls for unexpected 502/503/504 in both probe paths.

2. **major — `packages/cli/e2e/src/adapters/http/fetch-http-adapter.ts:15`; `packages/cli/e2e/src/application/gates/scaffold/runtime/probe-plugin-resource.ts:92` — Status evaluation waits for the response body.** Both paths read the body before rejecting an already-known wrong status. With actual 401 headers, expected 200, a delayed body, and a 100 ms gate deadline, `HttpGate` consumed approximately 104 ms and returned `failureClass: 'timeout'`, losing the served-status assertion. The byte limit does not bound the time needed to receive those bytes. **Fix:** evaluate status as soon as headers arrive, cancel the body on mismatch, and preserve an assertion failure independently of body completion. Add a slow or stalled-body regression test through the real fetch adapter and plugin probe.

3. **major — `packages/cli/e2e/src/adapters/http/fetch-http-adapter.ts:10`; `packages/cli/e2e/src/application/gates/scaffold/runtime/probe-plugin-resource.ts:83` — Automatic redirects hide the endpoint’s served status.** Neither fetch call sets a redirect policy. A route serving 302 to another route returning 200 `{ "authenticated": false }` passed both `HttpGate` and `probeExchange`, despite the exact-200 contract for the requested route. **Fix:** use `redirect: 'manual'` in both paths and evaluate the original response. Add a 302 → matching-200 negative control.
