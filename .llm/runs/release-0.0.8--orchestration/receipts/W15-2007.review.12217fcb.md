1. **major — `packages/cli/src/public/features/agent/init/hosts/opencode-config.ts:39` — Valid OpenCode configuration can abort installation.** The writer uses `JSON.parse`, which rejects comments and trailing commas. I reproduced this with an existing `opencode.json` containing a comment and trailing comma: OpenCode 1.18.35 accepted it and retained its model setting; `renderOpenCodeConfig` threw `SyntaxError`. Installation has already written shared assets before reaching this failure. OpenCode’s [upstream parser](https://github.com/anomalyco/opencode/blob/dev/packages/opencode/src/config/parse.ts) accepts JSONC with trailing commas. **Fix:** use the existing `@std/jsonc` dependency or a compatible parser, preserve unrelated settings, and add merge/idempotence tests for comments and trailing commas.

2. **major — `packages/cli/src/public/features/agent/init/init-agent.ts:192` — An existing JSONC configuration can override the installed MCP command.** Detection recognizes `opencode.jsonc`, but installation reads and writes only `opencode.json`. I reproduced a project containing a fresh command in JSON and an older `mcp.netscript.command` in JSONC: `opencode debug config` reported the older command. Re-running initialization therefore cannot reliably refresh the pinned CLI or repair MCP wiring, contrary to the PR’s stated behavior. OpenCode [loads both project configuration formats](https://github.com/anomalyco/opencode/blob/dev/packages/opencode/src/config/paths.ts). **Fix:** handle the effective configuration file and conflicting declarations explicitly, preserving unrelated configuration and comments. Add an integration regression covering an existing JSONC server declaration and verify the effective command after initialization.

3. **minor — `packages/cli/src/public/features/agent/init/hosts/agent-host-resolution.ts:105` — The printed source misclassifies an editor flag as project detection.** With no markers, `--editor vscode` produces `Agent hosts: vscode (from project: --editor vscode).` The editor line correctly reports `flag`. **Fix:** retain flag provenance when the editor flag selects the host and test the printed result.
