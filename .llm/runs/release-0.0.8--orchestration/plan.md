## Process contract (explicit, owner rules)
- **File ownership:** before EVERY leaf launch (not only per wave) the coordinator records the leaf's declared surface (paths) in `events.jsonl` and refuses to launch if a live leaf owns an overlapping path; overlaps become serialization.
- **Publication-dependent criteria:** boxes that can only be proven against a published canary/stable are marked `[post-merge]` (close-gate exclusion) or kept open with `Refs`, and get a named verification owner (internals lane after each owner canary cut; release captain for stable-only). They never block later implementation waves.
- At most **2 implementers live** at any time (owner fleet cap); raise to 3 only on owner word/free builder capacity. Waves dispatch topologically; C3 first; never one big fan-out.
- Merge only when: CI green on the exact head (named gates SUCCESS) **and** Sol `VERDICT: PASS` + `Verdict: MERGE at <that head>` **and** every review thread resolved (GraphQL `isResolved`) plus `check:review-threads` clean **and** local quality-gate output pasted in the PR. A new push invalidates the verdict → re-review at the new head.
- Closing keywords only for fully delivered issues; `Refs` for partial; umbrella #2103 is **reference-only** (`Refs rickylabs/netscript#2103`, never `Closes`).
- Publication is **owner-only**: no canary/tag/release by any agent; at each canary group boundary the coordinator posts the would-be content from first-parent merge history.
- **No committed run directory** (`.llm/runs/**` additions are a review blocker); run record = scratch events stream + state.
- **Golden rule 5** in every brief and review: background work runs in workers/sagas/triggers under a service identity, independent of any app or owner session being alive.

## Merge gate (coordinator only)
CI green on the exact head (named gates SUCCESS, not SKIPPED/CANCELLED) · Sol IMPL-EVAL `PASS` + `Verdict: MERGE at <head>` for that same head · **every review thread resolved** (GraphQL `reviewThreads.isResolved == true`, checked separately) **and** `check:review-threads` clean · local gate output pasted · zero unticked boxes on closed issues (mirror dry-run) · PR body checklist matches the diff · then `status:ready-merge`, CI re-run for close-gate, squash merge. Cut-trace appended from `git log --first-parent origin/main`.
