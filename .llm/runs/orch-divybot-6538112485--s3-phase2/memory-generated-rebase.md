# Generated carrier conflicts during rebase

The root Fresh UI `registry.generated.ts` is a gzip/base64 bundle generated by the root `gen:assets-barrel` task. The package `registry:embed` task writes a different file under `src/registry/assets/`; running that task alone does not resolve the root bundle. For a root carrier conflict, regenerate through `deno task gen:assets-barrel`, stage that actual output, and continue the rebase. After replaying all commits, regenerate and check all four carriers against the combined authoring sources.

The third latest-base integration preserved main’s contrast/token outputs byte-for-byte and kept its stricter browser baseline. Explicit protected-path diff checks prove this independently of a read-only reviewer’s inability to decode the compressed bundle. A passing integration review does not replace final IMPL-EVAL or exact-head CI.
