# CodeBlock implementation and validation

CodeBlock is copied application source. Hydrate it for Tabs and clipboard interactions; semantic runtime imports require the declared current Fresh UI dependency. The real installer test includes updated baseline code-block separately from the exact new-component list. Native DOM onCopy remains distinct from onCopied/onCopyError; clipboard state uses a request generation keyed by active file and raw source. Encode raw file keys for ARIA identifiers, then map callback values back to raw keys.

The D8 ledger axes are single/tabbed/diff × md/sm × default/destructive tone. Published phase-one variant/header aliases remain. Diff totals sit beside the filename; optional footer is line count/custom content. Native scrollbar/thumb and copy-title tooltip are platform internals. Syntax colors apply on code/bg; tinted diff/highlight rows temporarily use text/fg because mixed syntax/tint pairs fail strict AA. Exact values and restoration cost are in drift.md.

PReact SSR safely escapes opening angle brackets but need not escape closing angle brackets. Test the actual safe HTML and absence of raw script markup. In TSX a quoted attribute containing backslash-r/backslash-n is literal JSX text; supply a variable holding actual CRLF for an exact-source test.

For a single browser fixture file, run deno fmt with explicit --config deno.json from the repository root. Native formatter discovery otherwise selects the browser package defaults and flips its quotes; the root structured formatting wrapper then correctly rejects the inconsistent result. Browser fixtures compile with the generated gap bundle config; Node Playwright specs use docs.deno.json.
