# Native SVG series and responsive scroll tests

An SVG image with title/description already names the plotted series. Unroled g elements cannot carry aria-label; strict axe reports aria-prohibited-attr. Keep graphical groups unlabelled beneath the atomic image, and expose exact labeled values in a native table/disclosure. Never hide this with a broad axe allowance.

For native horizontal wheel tests, measure the actual viewport width. A fixed400px wheel distance spans more than one slide on narrow screens; one-slide keyboard controls and arbitrary native wheel distances are different contracts.
