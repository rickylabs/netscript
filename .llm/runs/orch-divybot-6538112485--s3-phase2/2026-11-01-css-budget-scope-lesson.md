# CSS budgets must name the inventory they protect

A fixed aggregate cap for 66 components can conflict with an approved 38-component
expansion. Measure both the new tree and the guard's reference baseline with the
same byte inventory and native compression algorithm before proposing rates.
Do not divide caps by file count to justify component credit, or set a threshold
from the failing candidate. A reviewed extension needs an independent fixed
approval list, actual registration/shipped CSS closure and negative controls.
When the guard's stated absolute policy conflicts with scope, preserve both
branches and raw evidence and record an owner decision; do not waive the gate.
An evaluator FAIL_RESCOPE and two terminal failures stop the leaf. Retain source
work and current contexts rather than erasing the conflict or retrying a third time.
