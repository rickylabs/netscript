- Memory's own acknowledged snapshot reads per key; no-extra-read proof needs the exact adapter read count plus zero bridge batch reads.
- Cancellation tests can verify cleanup without proving a missing ended guard; distinguish inspected guard correctness from what the observable test actually proves.
