# 2026-10-31 — Persisted projection changes need a reader census

Before changing a projection's JSON shape, find every reader of its storage table,
including restart reconciliation rather than only the HTTP mapper. In this slice,
independent review found the saga stream reconciler still consuming the old flat
Prisma shape. Sharing the document validator and adding a reverted-mapper control
proved the corrected startup snapshot matches the live business-state shape.

Count IO at the actual store seam and assert the keys, not just successful output.
A Promise.finally assertion keeps the two-read regression visible even when an old
scan returns NOT_FOUND before reaching the normal success assertions.

audits can pass while doc lint has existing privateTypeRef failures. Record both.
