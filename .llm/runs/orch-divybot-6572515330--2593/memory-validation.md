# Validation recipes

The root Deno lint/fmt configuration intentionally excludes CLI and .llm/tools. Scoped wrappers fail closed on that exclusion. For these owned files, pass --config "$TMPDIR/2593-fmt.json" with {"fmt":{"lineWidth":100,"indentWidth":2,"semiColons":true,"singleQuote":true}} and no include/exclude filters; wrapper processed counts must cover all selected files. --output also needs --allow-write on the wrapper launcher. Checking an external generated scaffold must use wrapper --cwd "$fixture/apps/<app>"; checking its absolute files from the repository cwd incorrectly applies repository isolatedDeclarations and import maps.

The provider boundary gate uses real Vite SSR builds, an inline npm poison edge, and built-output native-import execution over six capability states. --negative-control runs the mutation alone and should exit 1 with npm:@tanstack/ai@0.68.0. Default checks both clean and negative variants. Avoid adding root vite/zod aliases for internal tooling: reference projects inherit imports but not the corresponding catalog entries, and Fresh UI uses a frozen private lock. The gate uses the already-resolved Vite pin and Zod range directly (documented tool-only lint exception). No lock changes are needed.
