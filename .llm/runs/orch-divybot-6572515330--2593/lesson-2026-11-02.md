# 2026-11-02 — Optional providers and Vite graph ownership

- A lazy import.meta.glob is still a static build edge. Server-only provider registration can enter the SSR bundle even when no browser island imports it and no provider function executes.
- Read the failing build phase before calling a Vite failure a client-bundle failure. Here the client build completed; the new scaffold capability glob was the changed owner.
- Preserve native runtime module boundaries using a caller-discovered workspace root, not the rewritten location of a bundled module. Test the built output from a different directory.
- Published JSR inline npm imports and cache initialization can differ from local workspace resolution. A controlled provider edge with the original emitted specifier makes a useful pre-publish negative control; it complements exact-version production E2E.
- Root import aliases affect isolated reference catalogs and frozen member locks. Keep an internal build probe's dependency footprint scoped instead of expanding consumer import maps for it.
