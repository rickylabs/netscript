# 2026-10-31 — Browser-auth reporting lessons

- Exact generator parity must compare the formatter's output, including on reruns.
- Authored browser topology and independently scaffold-owned service wiring are
  distinct ownership decisions. Keep the auth/service.ts exception and deduplicate
  candidates before reporting so the service helper is not falsely skipped.
- Lifecycle structured results can carry the existing DoctorReport with ok=true;
  normal command output renders those checks without changing the failure verdict.
- Report project-relative names: plugin update uses a staged project and must not
  display temporary locations after committing that stage.
- Root lint/fmt intentionally exclude CLI source. Focused structured wrappers need
  an explicit config retaining the root's formatting and lint rules while removing
  broad exclusions. The run's validation.deno.json provides that config.
- Authored app directories may resolve outside or equal to the project root. A
  reporting-only change must preserve that existing support: report their selected
  routes without inspection, and reserve strict workspace path validation for
  scaffold-owned writes. Regression tests should guard both reads and writes.
