# Lesson — observe both Fetch signal channels

The actual Fetch input can carry cancellation on a Request even if init.signal
is absent. Assert both the requested public init contract and observable pending
fetch cancellation. For dedupe, add mixed signalled/unsignalled callers and
independent settlement: all-input abort aggregation is not subscriber cancellation.
Keep positive dedupe and header-identity controls beside the RED regression.

Repository and consumer lock resolutions can differ under the same manifest
range. Record each actual graph; a stable-version lookup is not a corrective
experiment. During a parent-gated planning task, retain honest baseline RED and
the exact plan; defer source mutations and release qualification until authorized.
