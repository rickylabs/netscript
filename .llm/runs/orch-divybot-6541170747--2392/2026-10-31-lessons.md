# 2026-10-31 — worker logging lessons

Canonical loggers share configuration within a process. The API service's initialization does not
configure a separate background worker. Preserve diagnostic visibility when removing print statements;
prove configured Debug records, production Info silence, and unconfigured failure behavior separately.
A negative control that restores print statements catches lifecycle regression, while a second that
makes failures logger-only catches dropped diagnostics. Both are needed for this process boundary.
Direct dependency additions require maintained lock workspace metadata updates even when no package
version changes. Keep only the minimal membership diff and verify the dependency gate.
