- **A shell loop over gates can exit 0 even when every gate throws**, writing no receipt while a
  stale prior-slice receipt sits on disk looking current. Verify every receipt by `invocationId`,
  `gitHead == actualGitHead`, and `durationMs` — never by exit code alone.
- **Archive the previous slice's receipts by move, not copy**, into `receipts/slice-4-9cc8c4c5f/` (or
  the actual directory the worktree already uses for prior slices — check, don't assume), verified
  byte-identical before the move. A copy-then-recut leaves any receipt with no successor sitting at
