## What this leaf is

Both issues describe **runtime-correctness defects shipped in generated user code**, not cosmetic
template problems. That framing matters: the output of this generator is code other people run.

- **#1355** — `netscript service add --with-client` renders one template that is wrong three ways at
  once: every service exports the same `exampleService*` symbols; every service's cache keys live
  under the literal resource string `'service'`, so two services collide; and the generated
  invalidation constant addresses a key prefix no generated query ever produces, making the
  showcase's "Invalidate list cache" button and its optimistic `onSettled` reconciliation **silent
  no-ops**. There is also no verb at all for a second service.
- **#1360** — the canonical island computes `cachedAt` in its loader, threads it through as a prop,
  and then uses it only as a display label, never as `initialDataUpdatedAt`. So first paint tells
  TanStack the server snapshot is fresh as of hydration. The seam added by PR #1265 ships
  unexercised in the one example the scaffold designates as canonical — and a downstream consumer
  independently made the same mistake, which is evidence the seam is undiscoverable rather than
  unwanted.
