## What Slice 2 proves

Every call follows **prepare → immutable prepared call → transport**; omitting contributions is
byte-identical to today's baseline; ordinary retries prepare **once**; iterator reconnects prepare
once **per new epoch**; and private/upstream adapter identities never leak.

## Hard constraints

- **Nothing new becomes public.** There is **no** `src/internal/client-contributions/mod.ts` and **no**
  `deno.json` internal subpath. `client-link-factory.ts` extends the existing package-internal
  structural seam and **remains unexported**.
- Gate 4 is an **absence** proof: `deno doc --json` over the SDK root, `./client`, `./ports`, and
  `./desktop` must show none of the three ports, the prepared-call types, or the private symbol.
- Gate 5 is a **packed-consumer negative**: `@netscript/sdk/internal/client-contributions`,
  `.../adapter-ports`, and `@netscript/sdk/client-contributions` must all fail to import.
- Prepare-once semantics are the heart of this slice. Gate 1 (forced unary retry, `context.retry: 1`)
  requires preparation count **exactly 1** with a fresh transport header container per attempt and
  byte-equivalent contributor headers/context/procedure projection. Gate 2 (iterator reconnect)
  requires preparation count **2** across an epoch rotation, byte-equivalence within each epoch, and
  **abort starting no epoch**.
- Callbacks must see only the RFC snapshot — never SDK retry/cache/trace state (gate 3).
