## Scope — this is the reverse of Slice 6's mapping

Slice 6 projected `NetScriptProcedureMeta.access` **forward** into OpenAPI `security`/
`x-netscript-roles`. Slice 7 defined `OperationAccessSummary` as the target shape. **This slice
derives `OperationAccessSummary` back out of the already-retained raw OpenAPI operation**
(`IndexedOpenApiOperation.operation`, confirmed in `operation-index.ts` to retain the operation
without mutation) and populates it into both `list_service_operations` and `get_operation_schema`.

**The exact reverse mapping — do not invent a different one:**

- `security: []` → `authentication: 'none'`, `securitySchemes: []`, `scopes: []`, `roles:` from
  `x-netscript-roles` if present (though Slice 6 never sets roles alongside `none`).
- `security` containing an empty-object alternative (`[{}, { bearerAuth: [...] }]`, Slice 6's
  `optional` shape) → `authentication: 'optional'`, `securitySchemes` from the non-empty alternative's
  keys.
- `security` with no empty alternative (`[{ bearerAuth: [...scopes] }]`) → `authentication:
  'required'`, `scopes` from that requirement's array, `securitySchemes` from its keys, `roles` from
  `x-netscript-roles` if present.
- **No `security` key on the operation at all** (undeclared — Slice 6 never touched it) →
  `access` stays **absent** on the result, exactly as Slice 7's doc comment already states
  ("absent when access is undeclared"). Do not synthesize a summary for undeclared operations.

**Curl guidance must distinguish all four states — public, required, optional, undeclared — without
handling secrets.** "Without handling secrets" is a hard constraint: never solicit, embed, or echo an
actual credential value. A placeholder describing *how* to add one (e.g., naming the header) is fine;
a fabricated-looking token value is not. The existing `OPENAPI_CURL_AUTH_NOTE` generic caveat is the
correct behavior for the **undeclared** state specifically — keep it there unchanged; do not weaken it
into a false "no auth needed" claim just because metadata happens to be absent.
