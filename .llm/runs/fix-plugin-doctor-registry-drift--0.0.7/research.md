- What changed vs the carried-in description:

    invent a stream registry or claim stream coverage.

## Open Questions Resolved

- **Where does discovery truth come from?** The same installed runtime manifest discovery used by
  `generate plugins`, exposed as per-registry source file evidence.
- **What counts as a registry entry?** A generated registry's relative source import whose binding
  is referenced by the module body. Package/type imports are excluded.
- **How is drift surfaced?** A workspace report with one check per declared registry. Errors name
  each missing/orphaned source file and end with `Run: netscript generate plugins`.
- **What is not claimed?** Non-manifest, non-registry runtime topology—including the current streams
  plugin—is not certified.
