# 2026-10-28 — deadlines must cover startup and descendants

A timer inside a checker cannot bound dependency loading before its module graph executes.
Start the timer in a registry-independent launcher and retain shorter deadlines around individual
compiler invocations. Use the actual incident log to locate which side of that boundary stalled.

Waiting for the direct child’s exit is insufficient: inherited output pipes can remain open in
descendants, and a child may ignore graceful termination. Give each invocation an owned process
group, escalate to forced termination, and keep cleanup bounded. If a worker creates additional
compiler groups, forward parent termination to them as well. Exercise those shapes with real
subprocesses, not a mocked timer.

Measure timeout margins from successful executed jobs, excluding queue wait and skipped builds.
Keep steady-state timing separate from cold-network anomalies. An unavailable runtime preflight
is unproven evidence; it cannot be reported as a passed gate.

Inspect generated reporter files before committing run evidence. Their automatic resource
identities can violate a public-record privacy constraint even when no secrets are present.
