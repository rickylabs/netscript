# Lessons — 2026-10-31

- Native anonymous request types need one structural owner. Derive AnonymousRule and
  AnonymousRequestMatch from AuthnOptions rather than exporting more downstream facade names.
  This preserves exact native identity and fixes recursive private-type-ref without cap growth.
- Native auth defaults protect /api. Raw streams hosts select their intended protect prefix
  explicitly; forwarding an authenticator alone does not secure /v1/stream routes.
- Use the native runtime and producer for worker integration. Observe registered jobs in its
  actual stream snapshot, and stop caller-owned dependencies explicitly after worker shutdown.
- Group additional factory conformance owners under services/src/tests so native coverage does
  not widen source folders past cap12. Preserve legacy targets when extending exact export tests.
- Characterize a suspicious route on exact main before fixing it. Workers OpenAPI500 is baseline;
  new startup policy preserves parity while authentication, SDK/RPC and SSE remain verified.
- Checked compiler children need an explicit bounded compilation budget; keep runtime and
  stuck-child negative budgets separate. Two isolated failures justified the30s compiler caller.
- Skipped runtime CI is unproven. Label ownership and independent reviewer terminal limits cannot
  be bypassed by local tests, a green different head, or a new evaluator session.
