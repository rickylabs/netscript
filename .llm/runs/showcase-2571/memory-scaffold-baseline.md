# Scaffold snapshot and preview notes — 2026-11-01

A real public init fixture can capture the entire emitted file set without network
by passing --ci --no-agent --no-git. Keep the real ProcessPort: resource-slice rendering
formats source through it, and a noop returning stdout:'' fails the owned-leaf LF
contract. Normalize only temporary root/parent paths before SHA256; compare all files.
The pre-preset baseline has 192 files (db none) /232 (SQLite orders).

For new dry-run projects, auth discovery reads the root directory after exists().
The dry-run adapter must overlay recorded directory children rather than delegate to
an absent real directory. The new Northwind dry-run tests exercise this integration.

A local generated AppHost needs its Deno workspace dependencies materialized before
Aspire's TypeScript check: run deno install --allow-scripts, then aspire restore.
Without materialization the helper zod imports cannot resolve. This is an environment
preparation step; do not change dependency versions or claim a missing module is a
schema/runtime failure.
