# Lessons — 2026-11-01

- A post-merge evidence block can cite a valid main merge commit and an unreachable
  squash branch head in the same sentence. Check every selected citation; accepting
  any one reachable commit would silently weaken the safety contract.
- Numeric CI run IDs resemble hexadecimal SHAs. Treat bare mixed hexadecimal words
  of normal SHA abbreviation length as citations, and accept numeric/short hashes
  only with explicit commit labels or commit links. Full SHA-1 hashes are unambiguous.
- Evidence comments may be past the first API page. Paginate the new mode while
  preserving the existing CI read path as required by the compatibility contract.
- A source wrapper can correctly refuse files excluded by the repository lint config.
  Keep its refusal, then run the wrapper with explicit file selection and the same
  lint rules without exclusions; do not call zero processed files a pass.
- Real-data dry-runs can expose issue-authoring mismatches. #2524 has checkbox lists
  under headings the shared acceptance parser does not recognize. Report the exact
  refusal and preserve the existing parser policy.
