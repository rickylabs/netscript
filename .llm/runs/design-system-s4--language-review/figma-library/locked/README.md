# Locked theme renders

These are the approved example screens for each theme, reviewed over eight rounds. **They define each theme's identity and set the UI quality bar.** When the component library, the archetype screens and these renders disagree on composition, anatomy, shape, type or density, these renders win.

| File | Theme |
| --- | --- |
| `studio--neutral-ink--{light,dark}.png` | **Studio Utility**, the NetScript default (Neutral × Ink) |
| `studio--states--neutral-ink--{light,dark}.png` | Utility interaction states |
| `studio--<flavor>--{light,dark}.png` | Studio flavors (Slate Blue, Sand Orange, Mauve Violet, Atelier, Ledger, Signal, Contact) |
| `<theme>--{light,dark}.png` | Tonal, Bloom, Brutal, Cupertino, Filigrane, Fluent, Liquid, Pixel, Tactile, Terminal |
| `<theme>--components.png` | Locked component sheets, where they exist |

The library's own review renders are in `../review/`, and each theme's written rules are in `docs/design-system/themes/<theme>/DESIGN.md`. The PNGs are quantized to 256 colours.
