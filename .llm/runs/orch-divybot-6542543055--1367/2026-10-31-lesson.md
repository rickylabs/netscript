# Lesson: prove the actual generated host path

A plugin's Aspire contribution can be correct while generated projects still miss the behavior:
current AppHosts use a separate CLI registration renderer. Trace both paths before changing either.
Use a shared declaration primitive and keep filesystem effects at the AppHost edge.

For persistence acceptance, assert nonempty business events before restart, then compare the full
history after a real resource restart. Merely calling flush or checking durable:true cannot detect
silent write loss. Delete only the generated binding as a negative control: the exact proof should
fail on memory health rather than reporting a fabricated persistence PASS.
