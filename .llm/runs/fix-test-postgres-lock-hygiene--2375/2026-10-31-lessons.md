# 2026-10-31 — generated-fixture lock hygiene

Dynamic imports from a generated scratch module can still participate in the parent test process lock graph even when the scratch config sets lock:false. Derive the npm range from the workspace catalog and require its existing lock entry; never copy an obsolete range into runtime fixture text. Frozen negative proof catches the stale import without mutating the tracked lock. Assert global lock identity after the complete combined suite as well as inside the fixture, and perform cleanup in finally.

A noexec host TMPDIR breaks both fake shebang executables and compiled-binary tests. Verify an executable task-owned TMPDIR and rerun failures without weakening tests. Record the first failed attempt honestly. Native git may be necessary for canonical worktree placement when an environment wrapper redirects git worktree add.
