## 1. Upstream release facts (13.4.6 → 13.5.3)

Source: `sources/aspire-whats-new-13.5.md`, `sources/github-release-v13.5.{0,1,2,3}.md`.

| Version | Date       | Content relevant to NetScript                                                                                                                                                                           |
| ------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 13.5.0  | 2026-08-18 | Feature release (below). Breaking changes §3.                                                                                                                                                           |
| 13.5.1  | 2026-08-21 | **Polyglot AppHosts on the 13.5 SDK crashed under an older 13.4.x CLI** (`MissingMethodException`, aspire#19503) — fixed by capability probing in codegen. DCP 0.25.13 (macOS polyglot startup crash).  |
| 13.5.2  | 2026-08-21 | Windows CLI archive housekeeping only (`hex1bpty.exe` removed).                                                                                                                                         |
| 13.5.3  | 2026-08-25 | Dashboard graph-view crash for multi-path icons; **proxyless port allocation now limited to compute and container resources** so DevTunnel URLs reappear in Dashboard and MCP snapshots (aspire#19625). |

Adoption target: **13.5.3** (first patch with both the codegen-compat fix and the port-allocation
narrowing). Nothing in 13.5.1–13.5.3 is TypeScript-API-shaped; the API reference reports 13.5.1.

**Known issue (release page, "Mixed Aspire 13.4 and 13.5 packages can fail at runtime"):** the 13.5
SDK/core packages are not binary-compatible with some 13.4.6 hosting integrations
(`MissingMethodException`/`TypeLoadException`; explicitly lists `Aspire.Hosting.JavaScript`). Every
`Aspire.Hosting.*` pin must move to the same 13.5.x train in one commit. NuGet availability on
2026-08-29: PostgreSQL/MySql/SqlServer/Redis/Garnet/JavaScript 13.5.3 stable;
`Aspire.Hosting.Browsers` **preview only** (`13.5.3-preview.1.26425.3`);
`CommunityToolkit.Aspire.Hosting.Deno` and `.SQLite` 13.5.0 stable.
