# Stale-surface inventory — every Aspire-bound surface, one authoritative source, one disposition

> Coordinator scope expansion (owner, 2026-08-29): Aspire 13.5 is a whole-ecosystem alignment. This
> table is the single place where every surface that encodes an Aspire version, behaviour, or API
> gets (a) the **authoritative current-version source** it must follow and (b) the **repo-path
> disposition** — which slice mutates it, which gate keeps it honest, or why it is archival-exempt.
> Built from
> `rtk grep -rnE '13\.4\.[0-9]\|13\.4-\|13\.3\.\|13\.2\.\|13\.5\.0-preview\|Aspire 13\.[0-9]\|aspire#[0-9]+\|verified against'`
> over the branch head (excluding `node_modules`, `.git`, `deno.lock`) plus the Explore audit.

Authoritative-source vocabulary:

- **A-SCAFFOLD** — `SCAFFOLD_VERSIONS.ASPIRE_SDK` / `SCAFFOLD_ASPIRE_INTEGRATIONS.*` in
  `packages/cli/src/kernel/constants/scaffold/` (product truth for generated projects).
- **A-TOOLCHAIN** — `.github/toolchain.env` (`NETSCRIPT_ASPIRE_CLI_VERSION`/`SDK_VERSION`), which S1
  makes equal to A-SCAFFOLD and the parity gate enforces.
- **A-UPSTREAM-TS** — aspire.dev TypeScript API reference (`/reference/api/typescript/<module>.md`)
  - the `apphost.mts` fences of the 13.5 What's New (retrieved copies in `sources/`).
- **A-UPSTREAM-CLI** — aspire.dev CLI command reference pages (`sources/aspiredev-reference_cli_*`).
- **A-RECEIPT** — executed evidence under `receipts/` (S2 runtime pass, S9 MCP smoke).

Parity-gate column: **enforce** (S1 gate `check:aspire-version-parity` fails on mismatch),
**derived** (regenerated by a generator; gate is the generator's drift check), **archival-exempt**
(historical/design evidence; never rewritten; listed so "all static resources" does not mutate it).

## Archival exemption list (explicit, for the parity gate and for S9/S11/S13 authors)

The following paths are **never** rewritten by the epic even though they contain `13.4.6`, `13.3`,
`aspire mcp start`, or other version-bound text. They are evidence of what was true when written;
changing them would falsify history:

1. `.llm/runs/**` (all prior run dirs) and `.llm/tmp/**`.
2. `.llm/runs/research-aspire-13.5-adoption--0.0.7/**` — the **entire** research run dir (plan,
   research, drafts, `sources/`, `receipts/`, `plan-eval*.md`, `tools/`): protected evidence (D-16).
   2a. `.llm/harness/debt/arch-debt.md` (dated debt entries; slices append/update their own
   entries). 2b. Compat-fixture class (checked for the 13.5.3 case, never for absence of 13.4.6) and
   `**/deno.lock` (excluded from sweeps).
3. `resources/design/dashboard/**` (design corpus, including `reference/**` snapshots).
4. `docs/site/_plan/**` (documentation planning corpus).
5. `rfcs/*.md` (RFC bodies; dated addenda are allowed, edits are not).
6. Version-suffixed fixtures: `packages/mcp/tests/fixtures/telemetry/aspire-13.4.6-*`,
   `.llm/tools/agentic/teardown/__fixtures__/aspire-ps-13.4.6.json`, and any `*-13.4.6-*` file S3
   leaves in place as a compat case.
7. `packages/cli/src/public/features/agent/init/fixtures/prior-release.mcp.json` (tests migration
   from a release that pre-dates the `aspire` MCP entry).
8. Branch-name examples in `.agents/skills/netscript-pr/SKILL.md` and its `.claude` mirror.
9. Changelog/release-note prose and closed-issue text (GitHub).

`check:aspire-version-parity` (S1) must carry this list as its exclusion set; a hit inside an exempt
path is reported as `info`, never `fail`.
