share it through native nesting under that identical selector. Zero-specificity root
rewrites need a different cascade design. Keep unscoped legacy rules outside groups.
Expand browser-parsed nested rules and compare ordered selector/declaration/media
contracts, then use real fixture computed styles and screenshots to test application.

Budget the shipped CSS bytes and assert equality with its authored inventory, so stale
carriers and new unbudgeted styles cannot produce a false pass. Measure the same native
gzip implementation CI uses. Protect shared generator source with complete output-body
comparisons, and prove regressions fail by changing one actual render path.
