# Lessons — 2026-10-31

- Registry imports only transpile generated modules. Empty mapped types can compile differently
  from populated ones; type-check the generated empty output for every writer path.
- A missing primary source directory does not imply no definitions: scan plugin-owned job folders
  before rendering. Empty and absent runtime registries are different states.
- Keep diagnostic severity in the host's existing warning vocabulary; adapter boolean completeness
  checks can stay compatible while admitting a complete empty registry.
- Use a fresh no-samples fixture for acceptance. Syncing plugin source can restore official sample
  jobs and invalidate a zero-definition premise even if no local jobs exist.
- Report focused runtime readiness and full Aspire orchestration as separate proof obligations.
