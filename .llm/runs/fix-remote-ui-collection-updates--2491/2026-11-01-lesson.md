# 2026-11-01 — Resolve collections before update guards

Remote collection identity belongs to the catalog, while installed identity belongs to the
lock. Qualify catalog membership once at the client boundary; select its installed intersection
before item resolution. This avoids adding uninstalled siblings while allowing partial remote
collections to update. Ordinary item updates should still work when the catalog is unavailable.
Prove no-write diagnostics by comparing complete filesystem snapshots, not just return values.
