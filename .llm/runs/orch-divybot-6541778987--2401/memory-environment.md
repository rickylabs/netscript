# Environment and publication

Deno 2.9.7 and Claude/gh are available; RTK is absent. Use focused raw git/gh reads and structured Deno validation wrappers. No connected memory tool is exposed; prior run memory files provide the saved recipes. The repo-native Claude print launcher supplies null stdin and same-session --resume. Raw logs belong outside Git; only sanitized review evidence goes in this run.

The issue-specific operator instructions govern this leaf: Refs issue body (no closure), no label/milestone edits, expensive scaffold runtime delegated to coordinator CI, stop at READY. The generic dispatcher closing-keyword/fan-out defaults conflict and are superseded by those explicit operator directives. Final report is delivered by atomic rename of excluded .divybot-final-report files, not by a direct issue comment.
