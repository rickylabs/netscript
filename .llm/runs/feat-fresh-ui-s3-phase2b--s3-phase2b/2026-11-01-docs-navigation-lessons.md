# Docs navigation lessons — 2026-11-01

Check actual computed semantic roles before expensive browser matrices. An
undefined font role can inherit a plausible platform default and pass dimensions
and axe. Compare the component family with a separate native reference using the
existing role, and assert a nonempty selection of used roles actually resolves.

Native fragment scrolling and passive section tracking must agree on offset
units. Computed scroll padding can remain a percentage; its basis is the owning
scrollport's block extent. Prove native landing geometry first, then let the
coalesced observer frame settle before checking the accepted current marker.
Exercise both document and nested scrolling, including short final sections.

A nullable current ID must never match an unresolved/foreign URL's null sentinel.
Tie DOM-derived labels and pinning to the accepted ID that was measured, so a
new or cleared controlled ID cannot display the previous section's text.

Nested navigation roots own their own links. Scope markers alone do not prove
ownership when the same component nests; use the nearest native/semantic
navigation root and retain an actual nested-component keyboard regression.

Keep exact computed CSS geometry assertions and a small common DOM precision
bound. Subpixel rectangle subtraction can expose tiny floating error even for an
exact44px CSS height. A1/64px bound in every engine preserves the geometry check
without retries or browser-specific thresholds.

Freeze source and build artifacts only after focused native regressions and
visual inspection. Interrupted/failed broad runs stay historical; a newer full
run must finish before it is a verdict. Archive terminal artifacts after process
cleanup, excluding transient automation directories, and keep raw captures,
receipts and resource matches private. Public reports contain verdicts/counts.
