# 2026-11-01 — Native table integration and test fidelity

- Check dynamic state changes in the real composition. Static selected fixtures
  and narrow-only neutrality missed WebKit subgrid cell displacement after a
  native Orders checkbox changed state. An inset logical rail preserves paint
  without inserting a generated layout box on the native row.
- Verify decorative paint through real pixels as well as geometry. Sample the
  correct logical edge, adjacent background and opposite edge with one fixed
  channel tolerance; prove missing-rail and wrong-edge mutations fail.
- Audit explicit selected-row hover. A global muted role can pass on the default
  surface and miss AA on its hover tint. A layout component owns its labels;
  the host owns its child control variant. Keep that boundary and track global
  role design separately in the existing theming issue.
- Use a separate native CSS container reference at fractional boundaries.
  Compare the component to the engine's complementary query result and keep
  exact anchors. Do not change a breakpoint to force cross-engine agreement.
- Native tracing can affect activation. Isolate only proven affected cases with
  file-level trace configuration and retain action/source/screenshot evidence.
  Keep the runtime behavior and assertions; collection errors are not passes.
- Treat full green runs as historical when later source changes. Archive entire
  result trees before another Playwright run, and retain raw logs privately.
  Public evidence is portable verdicts/counts; audit added lines before pushing.


Native subgrid wrapping needs two-dimensional containment. Proving that a long
span wraps inside its column does not prove its row grows around it. Actual
WebKit captures caught text crossing the next row despite green horizontal
geometry/axe cases. A red-first line-bound check inside both cell and row now
protects this; content-sized group row tracks preserve the existing minimum
height role without an engine branch. Inspect native captures before source
review, and keep interrupted runs explicitly historical.

The resource reporter writes leak-report.md automatically under its slice
directory even though resource probing is read-only. Public runs retain verdicts
and counts only; put raw observations in the private run and audit both the
added-line diff and every public run artifact before pushing.
