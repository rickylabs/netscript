# Theme gallery images

WebP exports of the Orders specimen for every theme language and every Studio flavor, in light and
dark (`<theme>--light.webp`, `<theme>--dark.webp`). They come from the NetScript Figma library. The
docs Design system section (S8b) uses them as theme previews.

Studio flavors: `studio-utility` (the NetScript default), `studio-cloud`, `studio-workshop`,
`studio-playful`, `studio-ledger`, `studio-atelier`, `studio-signal`.
