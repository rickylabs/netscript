## Exact residue classes

The implementation must produce a tracked-search ledger with every remaining occurrence of:

- `qwen/qwen3.8-max`;
- `claude-evaluator-qwen-3-8-max`;
- prose variants of Qwen 3.8 used as a formal evaluator.

Allowed classes are only:

1. immutable completed run evidence, especially #1331 and milestone T1-B;
2. explicit negative/rejection tests proving the retired formal route fails closed;
3. generic OpenHands/open-model coverage where Qwen remains an actually supported non-default model;
4. historical lessons/debt/fixtures whose claim would become false if rewritten.

Everything else is active residue and must be removed or migrated. Each retained path, line, class,
and rationale belongs in the implementation worklog; an unexplained occurrence fails S3.
