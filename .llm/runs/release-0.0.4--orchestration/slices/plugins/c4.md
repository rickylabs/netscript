## Regression caught by CI and fixed — `plugin doctor` without the Aspire CLI

Commit `057f063e1`.

### What went wrong

Slice 2's AppHost inspector shells out to `aspire ps`. `DenoProcess.exec` uses
`Deno.Command(...).output()`, which **throws `Deno.errors.NotFound`** when the binary is not on PATH
rather than returning a non-zero code. That throw landed in the inspection `catch`, which produced
`status: 'error'` — so `netscript plugin doctor` **failed outright on any machine without the Aspire
CLI installed**, and equally if `<projectRoot>/aspire/` was absent.

CI caught it on `ba0bc937b`:

```
> behavior.plugins-health: Check installed plugin health
  FAILED 497ms
Summary: passed=15 failed=1        (scaffold-static, deno-only lane)
```

### Why both local runs were green and wrong

The implementer and I each ran `scaffold.plugins` locally and both got `passed=16 failed=0`. This
machine has `aspire` at `/usr/local/bin/aspire`; the CI **deno-only** lane does not. Our green was an
artifact of the environment. Recording it because a gate that has only ever run in one place is not
evidence.

### The fix

A third observation arm. The inspector previously had two states; conflating "I could not observe
this" with "this is broken" is the same error #1022 was filed about, just inverted:

| Condition | Status |
| --- | --- |
| Aspire CLI absent / not executable / `aspire/` missing — cannot observe | **`warning`** (`apphost:inspection-unavailable`), naming why it was skipped |
| AppHost inspected, not running | `warning` |
| AppHost running, resource missing or unhealthy | `error` |

A working `aspire` that returns non-zero still throws and is still an inspection **error** — only
`Deno.errors.NotFound` degrades to `unavailable`.

### Verified in the environment that was actually failing

Re-ran the gate with `/usr/local/bin` stripped from `PATH`, so `aspire` genuinely does not resolve
(`deno` and `docker` still do) — a local reproduction of the CI deno-only lane:

```
> behavior.plugins-health: Check installed plugin health
  PASSED 892ms
Summary: passed=16 failed=0
```

Plus regression tests that inject a process whose `exec` rejects with `Deno.errors.NotFound`,
asserting doctor reports `warning` and exits **zero**: `31 passed | 0 failed` across the doctor and
inspector suites.
