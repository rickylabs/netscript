# Carrier generation needs an intermediate commit

For docs/source changes, commit source; run gen:agent-docs-prose, gen:assets-barrel and gen:publish-assets; commit those package-generated sources; only then run gen:mcp-export-corpus. The export generator read-set guard treats generated package TS as source and rejects their dirty state. Do not bypass with --allow-dirty. Adding a tooling baseline with Aspire filenames changes the tracked text inventory; regenerate aspire-surface-manifest.tsv after staging its source. check:assets-barrel compares generated bytes to committed HEAD, so run after the carrier commit.
