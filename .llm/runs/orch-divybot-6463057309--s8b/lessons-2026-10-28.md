# Lessons — 2026-10-28

- A Lume generator page can own a new section without editing a shared config, preserving parallel UI ownership. Import the already-configured site only to obtain its Markdown hook.
- Markdown rendering must preserve the site's anchor plugins; a synchronous, finally-restored HTML option scope prevents raw template markup without changing other pages. Strip metadata comments before exposing HTML-disabled source prose.
- YAML parsing loses author comments. Pair recursive value tables with verbatim YAML to preserve contrast and provenance notes without writing a YAML-comment parser.
- Corpus heading checks are not enough by themselves. A fixture with a distinct sentinel per section, nested value assertions and intentional omission controls proves the regression test actually rejects dropped content.
- Built-site link checks exercise base_path rewrites and generated anchors together. Raw source checks cannot prove those routes resolve.
- Browser dependencies were already available as read-only project-local inputs; combine the existing Chromium library directories rather than installing system packages or touching caches.
- Preserve the runtime gate's failed exit independently of the docs verdict. This worker can build/serve/inspect documentation while its default .NET shim and Docker environment cannot run scaffold runtime gates.
