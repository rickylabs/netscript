## Do not

- Do not add a mutating action kind, a command palette, or anything requiring a credential-bearing
  typed client. Auth propagation is blocked on the RFC-A chain, which includes an **unfiled** child.
- Do not introduce a `DevToolsContribution` union, and do not `switch` over `contribution.kind` in
  the renderer — use the typed kind registry populated at the composition root.
- Do not let a plugin mint a zone name; zones are host-owned and closed.
- Do not make out-of-range `order` a runtime coercion — it is a **generate-time error**.
- Do not create a panel-per-seam `routes/` folder over a dozen children (AP-21); follow §11's
  vertical slicing.
- Do not populate a registry at module load or start a polling loop inline in a panel (AP-11/AP-25);
  §8's context is passed, never ambient.
- Do not use `console.*` in published code (AP-13) — a diagnostics package is the most tempting
  violator.

      `devtools-core` entrypoint; `deno task publish:dry-run` re-run because exports changed.

      supervisor review precedes each sign-off commit.
