## Hard dependencies

- **W5-a depends on W3-a**; **W5-b depends on W5-a**; **W5-a gates W6-a**.
- The §8 invariant is structural, not advisory: because no URL-shaped input exists anywhere in the
  contract, the confused-deputy shape is removed by construction. A single convenience parameter
  taking a path or origin re-opens it.
- MCP is composed **in-process, read-kind only**, and is **never** exposed over HTTP.
- SSE is **one-directional**. That is what forecloses the upstream `install-devtools` class of
  attack; a bidirectional channel would reintroduce it.

## Owner forks that must be resolved first

- **F-7** (read-only v1) — ratification bounds the procedure set.
- **F-18** (MCP is the agent surface, DevTools the human surface) — ratification is what keeps the
  MCP composition in-process instead of growing a second network surface.
- Credentialed data access is **blocked** on the RFC-A chain, which includes an **unfiled** metadata
  child. Do not attempt a credentialed panel in this wave.

## Do not

- Do not add a WebSocket or a MessagePort channel.
- Do not expose MCP over HTTP, and do not add a write/mutating procedure of any kind.
- Do not accept a url, origin, host, or path-shaped string as any procedure input — including
  "just for the dev proxy".
- Do not serve the read contract cross-origin; it is same-origin by design.
- Do not promote anything beyond `createSSEStream` in the `@netscript/fresh` export map. A promotion
  is a permanent public-surface commitment and a consumer-gated change.
- Do not omit the README "Required permissions" block (**F-9**); under INV-2 declared permissions are
  *enforced*, not advisory.
