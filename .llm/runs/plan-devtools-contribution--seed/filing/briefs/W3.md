## Do not

- Do not mount DevTools inside the scaffolded app, and do not add it as a `@netscript/fresh` subpath.
  A Vite-injection mount is unavailable repo-wide, an app-mounted tree inherits the full-reload
  watcher, and a `fresh` subpath inherits an unresolved A3/A4 archetype dispute plus a package
  already carrying a **Restructure** verdict.
- Do not publish the generated host as a package without a fresh archetype decision.
- Do not bind the host to anything but loopback, and do not add an auth story to compensate — v1 has
  no production tier at all.
- Do not implement production exclusion with a **single** signal. Upstream ships devtools into
  production builds with client auth disabled precisely because one signal was trusted; hosting
  providers set build command and mode inconsistently.
- Do not duplicate Aspire's resource/process/log/trace/metric/health UI or Scalar's API reference UI.
