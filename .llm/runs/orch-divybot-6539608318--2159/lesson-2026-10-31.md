# 2026-10-31 — test the composed crash boundary

An engine-only idempotency fix can pass while a durable bridge reservation still drops retries.
Crash proofs should run the production supervisor with its real marker stores, pause after the
handler, kill the process, reopen persisted state and redeliver. Include orphaned pre-upgrade markers.
An applied key proves a completed transition only when it shares the state/history transaction.
Keep atomic-state capability independent of worker-command support; adapter decorators must preserve
both guarantees exactly. Negative controls belong in an isolated verification tree so the reviewed
implementation remains stable. Use the existing command marker schema instead of another replay
ledger. Effect recovery is an additional transaction-plus-dispatch protocol and must remain explicit
until its restart, claim, acknowledgement and scheduler behavior is actually proven.
