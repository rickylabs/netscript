# 2026-10-31 — KV-only acceptance lessons

- A local import map does not prove an AppHost uses local service code. Assert and launch the package's actual service export; preserve versioned JSR identity for public installs.
- Empty registration generators must preserve promise/arity contracts and omit unused SQL/tool code. Populate workflows before claiming execution; an empty-registry doctor pass is only topology evidence.
- Checking restored Aspire SDK source with Deno requires NodeNext module-resolution compatibility and its declared nested JSON-RPC dependency. Use real source, not fake SDK declarations.
- Export auth credentials before Aspire. Credential-shaped appsettings literals are intentionally refused. The acceptance fixture uses public test material only, not a production login.
- Require exact child readiness and durable records, then stop the managed saga child and observe a separate ready runner advance state under duplicate/barrier messages. This distinguishes queue acceptance from execution and proves replay on the consumer graph.
