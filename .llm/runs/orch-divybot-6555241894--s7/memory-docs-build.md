# Native documentation and static preview recipes

Deno 2.9.7 native doc JSON has version=2, nodes[fileURL].symbols[].declarations[].def. Pass the prepared import map explicitly to deno doc and bundle; --config alone does not resolve the copied consumer imports reliably. npm import-map subpaths need explicit entries (preact/hooks, highlight.js/lib/common). Preserve registry target paths while stripping .template suffixes in build-only source. The generated tool config carries existing root catalog aliases and Lume mapping for structured scoped checks. Root lint excludes tools, so scoped lint needs the generated config to prove actual file coverage.

Lume base_path rewrites href/src, but does not rewrite data-* URLs. Construct browser iframe routes from the already-built iframe src, otherwise /netscript disappears. Native rendered placeholder gate sees adjacent JSX object braces as Vento; keep whitespace between those JSX braces in generated examples instead of adding an allowance. Generated references stay under the MCP byte limit and use the same compiled JSX as visible usage.

Independent review caught an actual theme bug: registry/theme/tokens.css is ns-one only; select and publish registry/theme/presets/<id>.css for every choice. Computed font/radius browser checks must compare semantic values against tokens.json (normalize only CSS quote/comma serialization). Preact render onto a main containing a loading paragraph retains that paragraph, so clear the initial placeholder before mounting. Public build output is .llm/tmp/fresh-ui-docs after adopting the neutral name.
