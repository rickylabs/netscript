- Figma Theme set is the owner of shared names. Resolve through its A/B aliases once; iterating Theme B after Theme silently overwrites active data. Source order reversal and inactive-mode perturbations in both directions are meaningful controls.
- Geometry, fonts and shadow/x also belong to the router. Old Bloom/Liquid core overlays disagreed with the fresh source; remove those value overrides rather than adding more case branches.
- Contrast role names are not enough: tooltip/kbd is a fill, and checking it as text manufactures near-1:1 failures. Model the actual paint stack. Chart and syntax coverage must explicitly reject removal/threshold weakening.
- Code-owned NS One compatibility aliases are a different provenance from Figma values. Keep syntax against the source's code background; mapping it to legacy muted creates avoidable failures.
- Public WEB role inventories, authored registry items, opt-in preview files and copied skill documents are separate carriers. Synchronize from TOKEN_PRESETS and the generated theme items, and preserve the frozen legacy baseline as an exact subset with explicit extension checks.
- docs/design-system/themes/ is a full component-spec and real-image catalogue, not a place for minimal token notes. Token-only additions live under token-presets/. Embed source docs by their declared install targets, so moving source folders does not drop published copy bytes.
- Stage deterministic carriers before running git-diff-based freshness checks. Regenerate corpus again from committed sources without --allow-dirty. Canonical gate receipts must show raw exit and immutable head; they prove the command, not that the source was clean or the merge gate set sufficient.
- Draft CI is skipped. After local gates and independent PASS, commit all evidence before triggering non-draft CI. Do not push after the decisive exact-head green; publish remote proof externally.
- Keep the six-KB CSS budget and five-MB native publish budget. Preserve all original NS One declarations and recursively add source-only dependencies requested by app aliases.
